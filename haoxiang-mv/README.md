# 好想好想你 · 我的日常，总会顺手想到你

为邓紫棋《好想好想你》制作的原创二维像素叙事歌词 MV（制作中）。

**当前状态：** 美术系统和三段样片已经完成，正在等待歌曲音频和歌词文件，之后再做全曲。

| 已完成 | 文件 |
| --- | --- |
| 调色与像素基础（360×640 逻辑画布，最近邻放大 ×3） | `src/core.js`、`src/texture.js` |
| 全身人物：正面、背面、左右侧面；走路、坐、伸手、拿东西；外套和长袖口；按镜头尺寸重新绘制（s = 1/2/4） | `src/people.js` |
| 半身人物：正面和侧面；眼睛、眉毛、嘴型、腮红；手臂与手 | `src/bust.js` |
| 第一人称的手：外套袖子、袖口过长与折起；他的手 | `src/hands.js` |
| 场景（都是正面立面）：玄关、街道（可横移）、车站长椅近景、夜宵摊、碗筷近景 | `src/scenes.js` |
| 界面：相机取景框（照片对齐与对比滑块）、视频通话 | `src/ui.js` |
| 样片 A / B / C | `src/samples.js` |

样片渲染出的文件在本地 `out/samples/`，不进 git。

全曲制作所需的流程与《阴天》《Love Song》相同：`tools/analyze.py` → `tools/asr.py` → `tools/align.py` → `tools/lyrics.js` → 镜头时间线 → `tools/build.sh final`。
