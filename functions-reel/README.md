# FUNCTIONS IN MOTION｜从一条线，到无限可能

120 秒数学动态设计短片（以 0.5 倍速播放 60 秒的故事时间线，所有动作都放慢了一倍）。画面、音乐、音效全部由代码生成，没有任何外部素材（图片、音频、视频、预制动画都没有；只用系统字体 Inter / FreeSerif / JetBrains Mono / 文泉驿）。

| 交付物 | 规格 |
| --- | --- |
| `out/functions-in-motion.mp4` | 1920×1080 · 30 fps · 3600 帧 · H.264 High · yuv420p · AAC 320k 48 kHz 立体声 · 120.000 s |
| `out/score.wav` | 配乐与音效，48 kHz / 16-bit 立体声；-13.9 LUFS，真峰值 -1.0 dBFS，115–116 s 为数字静音 |
| `out/keyframes.jpg` | 关键帧预览，每 4 秒一帧（30 张） |

## 运行

```bash
./build.sh                          # 约 10 分钟：配乐 → 3600 帧 → MP4 → 关键帧预览
node capture.js --frames 1200,1201  # 只渲染指定帧（帧号 = 实际秒数 × 30）
open "index.html?t=45"              # 浏览器里查看任意时刻（实际秒数）的静帧
open "index.html?play"              # 带声音实时预览（需先生成 out/score.wav）
```

依赖：Node + Playwright（Chromium）、Python 3 + numpy、ffmpeg。

## 结构

| 文件 | 作用 |
| --- | --- |
| `timeline.js` | 唯一的时间线：章节区间、每个动作和声音事件的时刻（故事时间），以及播放速度 `speed`。渲染器和 `score.py` 读的是同一份数据 |
| `core.js` | 无状态工具库：缓动、坐标相机、函数绘图（遇到无定义点和渐近线自动断开路径）、小球、HUD，以及一个小型 TeX 式公式排版引擎（斜体变量、上下标、分式、根号、积分号与上下限、lim 下标） |
| `scenes1.js` | 0–30 s：线 → 基本函数 → 图像变换 → 反函数 → 倒数 → 导数 → 定积分 |
| `scenes2.js` | 30–60 s：积累与变化率 → 复合函数 → 三角 → 极坐标 → 爱心 → 轮廓形变 → 回顾 → 静音 → Logo |
| `main.js` | 合成器：按 t 选择场景、需要两幅画面的转场、运动模糊 |
| `capture.js` | Playwright 4 进程并行截帧 |
| `synth.py` / `score.py` | numpy 合成库 / 编曲与音效 |

**播放速度。** 时间线里的时刻都是“故事时间”；`timeline.js` 中的 `"speed": 2` 表示整片以一半速度播放：实际秒数 = 故事秒数 × 2。改成 1.5 就是 90 秒版本，改成 1 就回到 60 秒原版。配乐的节拍网格始终是实际时间的 120 BPM，原来落在每一拍的动作，现在落在每隔一拍上，所以依然卡在拍点上。

**每一帧只由 t 决定。** 所有随机量都来自固定种子或整数哈希，帧与帧之间不保存任何状态，所以帧可以乱序、并行渲染；同一帧重复渲染结果逐字节相同。

**运动模糊。** 快速运动的时段（小球下落、镜头推进、甩镜、扫线、轨道、追踪描线）在帧内按半帧快门做 3–12 次时间采样，再求平均。公式和标注在每次采样中都不动，所以平均之后依然清晰。

## 时间线（实际秒数）

| 时间 | 内容 | 进入该段的转场 |
| --- | --- | --- |
| 0–4 | 一条线出现；小球落下挤压、回弹，线上激起衰减波，波平息成坐标轴；小球沿 y = x 滚出第一条斜线 | — |
| 4–12 | y = x → x² → x³ → \|x\| → √x，每个图形落定后才显示公式；√x 标出定义域 x ≥ 0 | 镜头沿斜线推进 |
| 12–20 | y = a·f(b(x−h)) + k：先 h、k，再 a（拉伸、反射），最后 b（\|b\| 越大水平越压缩，并标出宽度 2/\|b\|）；网格随变换联动 | 公式里的 h 放大飞出，成为顶点控制柄（小球） |
| 20–28 | 2ˣ 关于 y = x 空间翻折成 log₂x；小球从 (1, 2) 移到 (2, 1)，两个数字交换位置 | 网格沿对角线折起，折痕即反射轴 |
| 28–36 | 分屏对比：f(x) = x 与 1/f(x) = 1/x；只画已经访问过的输入，x = 0 处断开并标注无定义 | 反射轴收束成竖直分屏线 |
| 36–48 | 割线 → h → 0 → 切线 → f′(x) = 3x² − 3；切线颜色区分正、零、负斜率，极值点处 f′ 落在横轴上 | 小球沿曲线冲出，镜头甩镜追踪 |
| 48–60 | x² − 1 在 [0, 2] 上：矩形数 n = 4 → 8 → 16 → 32 → 64，每两拍翻倍；正负区域分色；结果为净积累 2/3（= −2/3 + 4/3），与几何总面积 2 区分开 | 切线立起、扫过画面，矩形随之展开 |
| 60–68 | F(x) = ∫₀ˣ(t² − 1)dt = x³/3 − x，与上方面积同步；F 的切线取 run = 1 时，rise 恰好等于 f(x)（两幅图同比例） | 面积化作粒子上升，按同一个 x 落到 F(x) 上 |
| 68–80 | g(x) = x − 1、f(x) = x²：3 → 2 → 4 推出 (x − 1)²；交换模块后 3 → 9 → 8 推出 x² − 1；f∘g ≠ g∘f | 两幅图收进两个函数模块 |
| 80–88 | 单位圆投影出 sin x；相位平移得到 cos x = sin(x + π/2)；改变 A、ω，背景点阵随之起伏 | 模块旋转成圆周轨道 |
| 88–96 | r = cos 3θ，每两拍长出一瓣（r < 0 时点落在反方向）；旋转 120° 自重合；视觉形变为 x = cos t, y = sin 2t | 波形卷回中心，变成极坐标轨迹 |
| 96–104 | 小球描出参数爱心，9000 个粒子旋入成形，然后柔和地搏动一次 | ∞ 的两环向外舒展 |
| 104–112 | 圆 → 椭圆 → 超椭圆 → 花瓣 → 爱心（360 点、弧长对齐）；中途展开成 25 层、9000 点的 3D 放样点云，再收回二维 | 爱心拆成轮廓上均匀分布的点 |
| 112–115 | 等距“数学城市”，之后 8 刀半拍快切回顾；每一刀只在第一帧加两条受控故障切片，不压到公式 | 轮廓点阵展开成等距网格 |
| 115–116 | 画面清空，只剩悬停的小球和一条线；声音完全静音 | — |
| 116–120 | 重击；小球落下成为 “FUNCTIONS.” 的句点，轻弹一次后落定；“Every curve tells a story.”，构图稳定保持约 2 秒，最后 8 帧淡出 | 线收缩回一点 |

## 声音如何对应数学

- 小球触碰：短促、有音高的敲击（马林巴）。
- 基本函数：每个图形落定时有一段滑音，音高曲线的形状就是新函数的形状。
- 图像变换：一个持续的音。k 抬高音高，a 拉伸音高、a < 0 时翻到下方；b 乘在频率上，与它乘在 x 上的方式完全一致；h 控制左右声像。
- 反函数：先在左声道奏出上行动机，翻折时声音从左移到右，再在右声道奏出它的镜像动机。
- 倒数：音高跟随 1/x，在逼近渐近线时持续攀升；x = 0 处是一声“无定义”的碎音。
- 导数：两个音的音程随 h 缩小，拍频逐渐放慢直至消失；之后主旋律的音高就是斜率 f′(x)，正斜率音色更亮，零斜率处响起钟声。
- 积分：每个矩形一个音；Δx 每减半，音符数量随之翻倍并多出一个和声声部，最终连成持续的音。
- 复合函数：输入、处理、输出各有一种声音，前后衔接。
- 粒子聚合：颗粒音的音高范围逐渐收窄，落到和弦音上。
- 爱心：温暖的和弦，加上一次轻柔的双拍心跳。
- Logo：低频重击，叠加一个清亮的高频瞬态，最后落在 D 大调加九和弦上。
- 整体编曲：D 小调，从稀疏的开头逐步加层；三角和爱心段落更旋律化；回顾段军鼓加速；115 s 起包括混响尾音在内全部静音（故事时间里的一拍）；最后自然衰减到约 −62 dB。

## 验收（实测）

- 时长 120.000 s，30 fps，共 3600 帧，1920×1080，yuv420p，音轨为 48 kHz 立体声。
- `blackdetect` 未检出黑帧。帧间突变只出现在设计好的位置：心跳、回顾快切、58 s 重击。
- 115–116 s 的 RMS 为 −240 dBFS，即数字零。真峰值 −1.0 dBFS，无削波。
