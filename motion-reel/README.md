# MOTION — 30 s 动态设计作品集

`out/motion-reel.mp4` · 1920×1080 · 30 fps · H.264 + AAC 320k · 30.000 s

全部由代码生成，没有任何外部素材（图片、音频、字体文件都没有引入，只用了系统字体）。

| 环节 | 实现 |
| --- | --- |
| 画面 | `reel.js`，Canvas 2D。`renderFrame(t)` 只依赖时间 t：随机数全部来自整数哈希或启动时的固定种子，帧与帧之间不保存任何状态 |
| 截帧 | `capture.js`，Playwright 无头 Chromium。4 个页面轮流分帧并行渲染（帧是 t 的纯函数，所以可以任意顺序渲染） |
| 音乐 | `music.py`，只用 numpy：加法合成锯齿/方波、FM 钟声、噪声鼓组、FFT 滤波、STFT 扫频、卷积混响、侧链压缩 |
| 合成 | `build.sh`，ffmpeg 合成音画并编码 |

```bash
./build.sh                         # 约 2.5 分钟：配乐 → 900 帧 → MP4
node capture.js --frames 780,781   # 只渲染指定帧
open "index.html?play"             # 浏览器里实时预览（需先生成 out/music.wav）
open "index.html?t=12.5"           # 查看任意时刻的静帧
```

## 时间线（120 BPM，每拍 0.5 s，每段 1 小节 = 2 s）

| 时间 | # | 技法 | 进入该段的转场 | 声音 |
| --- | --- | --- | --- | --- |
| 0–2 | 01 | 弹跳小球（挤压拉伸，3 帧触地，每次落地都在拍点上） | — | 下落哨音，每次落地一个马林巴音 A-C-E |
| 2–4 | 02 | 逐字动态排版（逐字错峰、回弹、字重 100→900 实时变化） | 从落点展开的圆形遮罩 | 每个字母出现时一个 tick |
| 4–6 | 03 | 形状变形（240 点按弧长重采样，outBack 插值） | 带运动模糊的甩镜推移 | 音高跟着 outBack 曲线走的 boing |
| 6–8 | 04 | 缓动曲线编辑器（贝塞尔手柄、播放头、间距图） | 上下对开门 | 正弦音的音高就是曲线的 progress |
| 8–10 | 05 | 9000 粒子拼字（“9000” → “粒子”） | 像素化 | 颗粒闪烁，成形瞬间响一声钟 |
| 10–12 | 06 | 纯代码 3D 点云（球 → 环 → 三叶结 → 波面，手写旋转与透视） | 百叶窗 | 每次变形一个气流音 |
| 12–14 | 07 | 液态元球（逐像素场、∇f 法线、Blinn-Phong，每拍融合） | 时钟扫描 | 水滴 bloop |
| 14–16 | 08 | 瑞士网格波（每拍触发一道涟漪，相互干涉） | 液体滴落擦除 | 每道涟漪一个木琴音 |
| 16–18 | 09 | 故障艺术（RGB 分离、切片位移、块损坏、像素拖尾） | 网格翻牌 | 8-bit 哔声，和视觉故障同频率、同强度 |
| 18–20 | 10 | 无限缩放（自相似嵌套，每拍一次推进） | CRT 关机 | 谢泼德音阶，听起来永远在上升 |
| 20–22 | 11 | 等距城市（画家算法排序，天际线随拍脉动） | 3D 翻卡 | 五声音阶琶音随楼群升起 |
| 22–24 | 12 | 单线谐波图（一条路径，9000 个顶点） | 斜线擦除 | 曲线本身变成声音：左声道是 x(s) 的分音，右声道是 y(s) 的 |
| 24–25.5 | 13 | 加速快切回顾（8 分 → 16 分 → 六连音） | 旋转缩放模糊 | 每一刀一记军鼓，音高逐渐升高 |
| 25.5–26 | — | 静音一拍：开场那颗小球再次落下 | 硬切黑场 | 数字静音 |
| 26–30 | — | 重击进入 Logo，小球落定成为句点 | 白闪、震屏、冲击波 | 低频轰鸣 + 镲 + Am9 和弦，小球每次轻弹都有 tick |

和弦进行：Am F C G ×3 → E（属和弦，制造张力）→ 静音 → Am9 解决。
