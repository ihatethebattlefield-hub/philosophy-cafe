# 设计说明

## 这一版改了什么

上一版的问题：细节粗糙，取景奇怪，画面里空地太多。具体是：

- 场景按 2× 取景时，地面占了半个画面，人物和家具挤在一角；3× 取景又会切到一片空地上。
- 多边形用画布路径绘制，边缘带抗锯齿，像矢量图，不像像素画。
- 家具是平涂的方块，没有描边、阴影和受光面。
- 特写画在 1× 的画布上，和场景的像素尺寸不一致，四周大片空桌面。

这一版的做法：

1. **重新布置每个场景**，让它从墙到最前景都是满的。房间里桌子贴着窗，前面依次是扶手椅、茶几、背对镜头的沙发和最近处的盆栽与篮子；3× 取景（窗 + 桌 + 茶几一角）因此是一个自然的中景，而不是一片地毯。
2. **扫描线多边形 + 描边形状**：所有形状都是整像素、带描边、阴影带和受光边。
3. **材质与光**：墙面颗粒、木板纹理和节疤、窗光的硬边多边形、窗棂投在桌上的影子、每件家具的接触阴影。
4. **特写统一到 2×**，并且放满：桌面上有书、手机、烟灰缸、杯子、收据、笔、旧杯印；手用描边形状拼出袖口、手背、手指和指甲。
5. **取景只用两种**：2×（全景）和 3×（中景），由镜头的作用决定，不随意推拉。

## 节奏

- 前奏：先是没有人的房间，再是她；杯子碰到照片，她把照片扶正。
- 第一段主歌：照片（合照）→ 烟停了 → 照片背面 → 进入照片里的小馆子。
- 第二段主歌：最初的同居片段，然后是"后来"的对照；同一画面三个时期。
- 间奏：厨房与门口的一次没说完的话；楼道里他停了一下。
- 副歌：现在的碗架（一个杯子）、桌边、收据（查看框）、走到窗边、车站第一次出现、各看各的晚上。
- 长间奏到第三段：婚宴，闪光灯 → 照片；钥匙放进碗里；他拿走外套、门关上，她先把地垫摆正才去看钥匙。
- 最后一段：再看一次（修桌腿、车站的钟走过 45 分钟）、椅子从有人到空、反打、最后一次看照片、烟灰缸冷了、她把照片挪到桌子里侧、窗玻璃里两个人变成一个、杯子凉了、她去续水、侧身朝窗坐下。

## 动作接触规则

- 先碰到杯柄，杯子才动；放稳之后手才离开。
- 先前倾，再站起来；坐下时落在椅面上。
- 先转头，再转身。
- 门先开，人再过。
- 环境运动保持很小：窗帘、云、经过的车在墙上的反光、呼吸、变淡直到停止的热气和烟。

## 音效

可选；为了不和人声冲突，这一版不加音效，只用原曲。
