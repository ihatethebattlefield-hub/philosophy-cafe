# 故事

**同一张桌子，三个时期。** 一个阴天的下午，她坐在不开灯的房间里，桌上是一杯已经不热的水、一张两个人的合照、一张折起来的收据、透明烟灰缸和一支圆珠笔。她整理这些东西的时候，画面在三个时期之间来回：

- **现在：** 阴天，不开灯。灰蓝绿的墙，旧木头，米白的东西。墙上只剩挂过画的浅色印子。
- **最初：** 蜂蜜色的光，砖红和黄绿。他端两杯水过来，把她的放在她习惯的位置；外卖挤满桌子，他挪开自己的碗让她放杯子；夜里他趴在桌上睡着，她把纸抽出来、把灯调暗。
- **后来：** 平光。她把一张纸放到他手边，他过了很久才注意到；一个看书，一个看窗外；一杯喝完了，一杯没动。

**两个人。** 她：齐肩短发，灰蓝宽松上衣，米色长裤。他：棕绿外套，深色裤子，只在回忆里出现。他不是坏人。第二次看同一时刻时会发现，他另一只手在修她那边晃动的桌腿；车站那天他跑来了，只是晚了四十五分钟。

**几个物件。**

| 物件 | 出现 | 后来 |
| --- | --- | --- |
| 合照 | 开头被杯子碰歪，她扶正；拿起来看（查看框：合照） | 背面"小馆子 · 四月 / 他说这张拍歪了"；进入回忆；婚宴的闪光灯接回照片；最后一次看，拇指擦掉灰；被挪到桌子里侧 |
| 杯子 | 已经不热 | 小馆子里白杯与蜂蜜色杯的位置和照片一致；碗架上只剩一个；最后续上热水，双手捧着 |
| 收据 | 折着压住照片一角 | 打开：小馆子，四月十七 19:42，红烧茄子被圈出来（查看框：收据） |
| 烟灰缸 | 最后一缕烟 | 烟停了；最后冷掉 |
| 钥匙 | 他从钥匙圈上取下一把放进碗里 | 她先摆正地垫，再去看那把钥匙 |
| 椅子 | 他的椅子 | 同一画面里从有人变成空的；反打时它的椅背在最前面 |

**结尾。** 没有重逢。她把照片从手边挪开，给杯子腾出位置，续上热水，侧身朝着窗户坐下。镜头不动。
