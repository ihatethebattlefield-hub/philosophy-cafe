# 故事设定《多远都要在一起 · 双人存档 / TWO CITIES, ONE SAVE》

## 一句话

两个人在两座城市，各自有房间、天气和作息。他们通过一首歌、一本书、一张照片和一张车票进入彼此的生活，最后走进同一张地图。

## 虚构设定（全片所有数字都以此为准）

| 项 | 设定 | 出现位置 |
| --- | --- | --- |
| 阿屿 | 住在**雾港**，时区 UTC+8 | 状态栏、存档 |
| 小晴 | 住在**晴川**，时区 UTC+3，比雾港晚 5 小时 | 状态栏、存档 |
| 时差示例 | 23:40 ↔ 18:40（开场）；06:10 ↔ 01:10（主歌 2：他的清晨、她的深夜） | 墙上电子钟、状态栏 |
| 距离 | 铁路 + 渡轮全程 2180 km | 状态栏「相距 2180 km」 |
| 剩余距离 | 按地图上尚未走完的路线比例计算；改签山线后列车上显示 392 km（约剩 18%） | 地图、状态栏 |
| 相识天数 | 开场第 214 天；结尾第 216 天（夜车加转车，第二天傍晚相遇） | 存档界面 |
| 站点 | 雾港 → 雾港北站 → 海峡渡口 →（渡轮）→ 风见站 ← 晴川站 ← 晴川；备用：雾港北站 → 山线 → 风见站 | 地图 |
| 风见站 | 中转站，两人相遇的地方，当地时间 17:20 | 站台、状态栏 |

## 物品（只有剧情里真的交到对方手上的东西才进背包）

| 物品 | 怎么来的 | 后来怎样 |
| --- | --- | --- |
| 一首歌（耳机图标） | 阿屿按下收音机播放键，小晴的耳机同时亮起 | 间奏时在背包里被重新查看；结尾在双人背包里 |
| 珊瑚色书签 | 阿屿夹在第 117 页；小晴在自己那本里翻到同一页、同一句 | 改签后跟着小晴一起出发 |
| 晴天小铺的照片 | 小晴傍晚六点拍下，门口的灯刚亮；照片放大成街道，阿屿后来在雨夜走进同一个街角 | 背包；结尾 |
| 车票（渡轮） | 阿屿在雾港北站买下 | 「想象你失约的旅行」时渡轮停航，车票作废 |
| 改签车票（山线） | 小晴选择「再次连接」之后改签 | 带着它到达风见站；结尾在双人背包里 |

## 界面何时打开、打开后改变了什么

- **存档（开场）：** 确认“继续”，面板收成一条线，这条线成为两个房间之间的缝隙。
- **双人状态栏：** 两人分开时一分为二，中间的空隙就是距离。相遇时两半合成一条。
- **收到物品：** 每次都对应画面里真实的交接动作。
- **地图：** 站点只有在人物真正到达后才点亮，任务进度按抵达的站点计算。
- **任务日志「去见你」：** 副歌 1 开启，副歌 2 两人抵达风见站后完成。
- **背包与选项（主歌 2 末）：** 小晴看过收到的东西后，自己选择「再次连接」。下一镜两人同时发出消息，路线改签。

## 与歌词的关系

歌词后半段有「你已经不再存在我世界里」「请不要离开我的回憶」这样告别式的句子。本片按你的设定，结局是团聚。处理方式是把这些句子放在剧情里最接近失去的时刻：
- 地图上的雾变浓
- 通话冻结
- 渡轮停航
- 屏幕两侧的手仍隔着缝隙

歌词照原样逐句出现，不改写。画面不对这些句子做字面图解，而是表现“害怕失去，所以更要去”。
