# 参考视频分析：《半岛铁盒》像素歌词视频

来源：用户上传的手机录屏（448×960，30fps，4:56）。以每 6 秒一帧抽样，另取两帧原尺寸细看。

**不属于 MV 本身、成片中一律不出现的部分：**
- 状态栏（时间、信号、录屏红点）
- 平台导航（关注 / 朋友 / 推荐）
- 点赞、评论、分享图标与计数
- 作者名与“免费听”入口
- 水印

## 真正起作用的表达方式

| 手法 | 参考中的做法 | 本片怎么用 |
| --- | --- | --- |
| 16-bit 生活像素 | 有木纹的地板、有书脊的书架、有光斑的台灯；颜色少而有层次 | 同样的密度，但换成自己的物件与配色：两种房间（冷蓝夜 / 暖琥珀黄昏），砖墙街道，车站 |
| 室内俯视 + 室外侧视交替 | 卧室、书店内景为斜俯视；街道、公交站为侧视 | 房间为斜俯视；街道、站台为侧视；地图为纯俯视 |
| 小人物全景 ↔ 第一人称手部特写 | 拿书、捧铁盒、伸手都用大比例的手，袖子颜色与人物一致 | 按播放键、夹书签、捧照片、贴玻璃、两手相碰都用手部特写；袖口固定为 A 蓝 / B 奶油 + 珊瑚 |
| 有功能的游戏界面 | 获得物品、加入队伍、合成、回忆图鉴、读取存档、今日结算、HP | 存档、背包、地图、任务日志、物品检查、双人状态、选项。每次打开都有原因，并改变下一步（见故事设定） |
| 同一地点反复出现 | 书店门口在晴天、雨天、不同季节出现 | 晴天小铺：傍晚的照片 → 雨夜阿屿走进；两个房间：开场 / 想念 / 同时发消息 |
| 固定的米黄色歌词栏 | 底部奶油色条，♪ 前缀，已唱部分变色 | 底部固定奶油色对话框、棕色像素边框、♪ 标记；逐字高亮只在有逐字时间时使用 |
| 克制的环境动画 | 雨、窗灯、人物呼吸 | 雨与水花、窗灯闪烁、台灯光斑、热气、呼吸与眨眼、围巾、路面反光、远处列车 |
| 铺垫—变化—回收 | 铁盒出现 → 打开 → 只剩回忆 | 书签、照片、车票、那首歌：先得到，中段在背包里被重新查看，结尾在“双人背包”里带着来源出现 |

## 可复用元素清单

- **人物：** 阿屿、小晴各一套。正 / 背 / 侧三视角；走路 4 帧；站立呼吸与眨眼；坐姿；伸手、递物、拿手机、捧书、举伞、遮阳、拥抱等手臂姿势。
- **地点：** 两个房间（镜像布局，可换时间与天气）、晴天小铺所在的街（傍晚 / 雨夜 / 晴天）、站台（雾港北站、晴川站、风见站）、两城地图、两人之间的夜空。
- **近景：** 收音机、书页、照片、手机屏幕、车站告示牌、火车车窗。
- **界面：** 存档、双人状态栏、收到物品提示、背包、任务日志、选项、视频通话、地图标签、歌词栏。
