# 美术规范

## 画布与像素

- 逻辑画布 360×640，成片按最近邻整数放大 ×3，得到 1080×1920。
- 所有绘制使用整数坐标，没有平滑缩放，没有渐变。明暗靠色阶和 4×4 Bayer 有序抖动表现。
- 画面区 0–560，底部 560–640 是歌词栏所在的暗带，所以歌词不会遮住人物。
- 中景用整数 2× 摄像机：场景先画进一半大小的缓冲区，再整数放大，整张画面保持同一套像素网格。界面始终是 1×。
- 近景（手、书、收音机）不放大像素，而是用更多像素来画：手的部件随分辨率 k 变大，轮廓线始终 1 px。

## 调色板（src/pixel.js `P`）

| 组 | 用途 |
| --- | --- |
| `night0–5` | 低饱和蓝紫：夜晚、分离、阿屿的房间 |
| `dusk0–4` | 傍晚的玫瑰到琥珀：小晴的城市、回忆 |
| `wood0–4`、`amber0–3` | 室内木头、台灯与窗灯的暖光 |
| `brick0–3`、`stone0–4` | 街道、站台 |
| `cream0–2`、`brown0–2` | 界面底板与边框、歌词栏 |
| `coral0–3` | 强调色：小晴的围巾、书签、已唱歌词、关键物品 |
| `blue0–3` | 阿屿的外套 |

**冷暖关系随剧情变化：**
- 分开时，上半屏冷、下半屏暖。
- 想念时，各自的灯在各自的颜色里亮起。
- 桥段里，雨后放晴的蓝和夕阳的琥珀被一道彩虹连起来。
- 相遇后，两人第一次站在同一片琥珀色的光里。

## 人物

| | 阿屿（A） | 小晴（B） |
| --- | --- | --- |
| 发型 | 深色短发 `hairA` | 棕色及肩发 `hairB`，有高光 |
| 衣服 | 蓝色外套 `blue0–2`，白领口 | 奶油色毛衣 `cream0–2` |
| 配饰 | 琥珀色星形别针（胸前一个像素点 `amber2`；手部特写时是袖口纽扣） | 珊瑚色围巾（走路或有风时尾端飘动） |

- 身体比例 12×20：头 9–10 行、躯干 6 行、腿 5 行。两人同一体型，站在一起时高度一致。
- 手臂按姿势从肩 → 肘 → 手绘制，手的位置固定在可信的高度：拿手机在胸前，递物在肩高，遮阳在额头，拥抱绕到对方背后。
- 走路 4 帧（约每秒 8 帧姿态）。身体在过步帧抬高 1 px，移动速度和步幅匹配，脚不打滑。
- 站立时每 3.2 秒呼吸一次（头部起伏 1 px），眨眼约每 3.7 秒一帧，两人错开节奏。

## 环境

- **房间：** 镜像布局，A 的窗在左，B 的窗在右，结尾“共同的窗”居中。
  - 墙纸竖条，B 的墙纸带小花点。
  - 窗外城景的灯会偶尔熄灭再亮。
  - 书架书脊随机但固定。
  - 墙上有日历和显示当地时间的电子钟。
  - 桌上有台灯（抖动光斑）、收音机、杯子（热气会随时间变弱）、书、手机。
  - 床、地毯、绿植。
- **街道：**
  - 砖墙楼房，层数随画面高度增加。
  - 一楼是「晴天小铺」：珊瑚和奶油相间的雨棚，亮着的货架橱窗。
  - 17 路公交站，路灯和光锥。
  - 湿路面上有灯和橱窗的倒影、水洼，雨丝和落地水花。
- **站台：** 远山、轨道、带亮窗的列车、黄线、立柱、站牌、长椅、灯光池。
- **地图：** 夜蓝色海面，奶油色陆地，雪山，铁路虚线，渡轮线，未探索的雾。站点只有真正到达后才点亮。

## 界面

- 奶油底板，深棕双层像素边框，四角缺口，标题牌嵌在上边框。
- 字体：
  - 正文与歌词：文泉驿点阵正黑 12 px / 10 px。
  - 大字：Unifont 16 px。
  - 两者都是点阵字形。渲染后按阈值二值化，每个字由整像素组成。
- 光标是珊瑚色的小三角，0.8 秒闪烁一次。
- 面板以整像素位移落下或滑入，不做平滑缩放。
