# 美术规范

## 画布与像素

- 逻辑画布 360×640，最近邻整数放大 ×3，得到 1080×1920。全程关闭平滑。所有绘制使用整数坐标。
- **景别与像素：**
  - 全景（街道、广场、夜空）在 1× 画。
  - 室内与人物中景：场景先按真实比例画进 180×320 的缓冲，再整数放大 2×（少数近中景 3×）。
  - 近景（手、纸、杯、滚筒、车轮、餐巾纸、速写本）直接在 1× 用更多像素画，不放大像素。
- 字幕是独立的 270×480 层，放大 ×4 叠在成片上：48 像素高、整像素的点阵字。
- 灯光是几层硬边半透明的椭圆和光锥，不用抖动噪点。抖动只用于开场的像素溶解。

## 调色板（src/pixel.js `P`）

| 组 | 用途 |
| --- | --- |
| `cream0–4` | 奶油白：纸、墙面、杯子、她的领口 |
| `honey0–4` | 蜂蜜黄：电车、灯光、木吉他、他的铅笔 |
| `brick0–4` | 砖红：她的贝雷帽、砖墙、电车腰线、被改掉的音符 |
| `sage0–5` | 鼠尾草绿：她的毛衣、咖啡馆墙板、洗衣房招牌、植物 |
| `ink0–5` | 墨蓝：他的裤子、夜空、墨迹、轮廓线 |
| `wood`、`stone`、`skin`、`hair` | 木地板与家具、街道与站台、肤色与发色 |

**时间推进（src/world.js）：** 下午 → 金色时刻 → 日落 → 蓝调时刻 → 夜晚。
- 每一刻都有自己的四段天空、环境色和透明度、太阳光色和亮灯程度。
- 房间里的阳光斑随时间移位、变暖，入夜后消失，由台灯接手。
- 街上的窗灯按各自的随机阈值依次亮起。

## 人物（src/sprites.js）

两人同一套 16×34 的身体结构（头 15 行、躯干 11 行、腿 10 行）。头和躯干是按规则生成的像素网格：先描轮廓，再画头发、五官、衣服。腿和手臂每帧按关节绘制，带描边。

| | A 阿程 | B 小满 |
| --- | --- | --- |
| 外形 | 乱一点的深色短发，一撮翘起；耳后夹着一支铅笔 | 深棕短发，砖红色贝雷帽 |
| 衣服 | 墨绿外套敞开，奶油色 T 恤，墨蓝裤子，棕色鞋 | 鼠尾草绿毛衣，奶油色领口，帆布包斜挎带；墨蓝裙子，深色袜，棕色乐福鞋 |
| 习惯动作 | 手指敲节奏，犹豫时整理袖口、折纸角 | 画小鸟，把杯柄转向左边，先听、再判断 |

- **动作：**
  - 4 个方向、6 帧走路（过步帧身体抬高 1 px）、坐。
  - 手臂姿势：放桌上、写字、伸手、递、捧、拿本子、整理袖口、举手、指、插兜、拎包。
  - 表情七种：普通、眨眼、笑、抬头、低头、害羞、说话。
  - 眨眼约每 4 秒一次，呼吸约 3.6 秒一次，两人错开节奏。
- 走路由位置函数决定：起步与停步都有加减速，步幅随移动距离推进，脚不打滑。
- **近景一致：** 手部近景的袖子与全身精灵一致。
  - 他：墨绿外套、奶油色 T 恤袖口、一粒蜂蜜色纽扣。
  - 她：鼠尾草绿针织纹理、奶油色袖口。
  - 手指可以单独抬起：抬起的手指短一格，影子留在桌面上，旁边有两笔敲击线。
- **路人：** 两个路人用同一套身体结构。其中一个从背后看和她相似，深红色帽子，在车站擦肩时用到。

## 场景

- **他的房间：**
  - 奶油色墙上有一块比周围浅的长方形，以前挂过画。
  - 架子上的唱片和小音箱，一幅挂歪的海报。
  - 吉他靠墙，键盘在支架上，落地灯。
  - 地上散着几个揉皱的纸团。
  - 床角，洗衣篮里露出一只袜子。
  - 窗台上有垂下来的绿萝，窗外是对面的砖楼。
- **咖啡馆：**
  - 鼠尾草绿墙板，长窗外是街和电车，玻璃上是反着的 CAFÉ，窗台上有植物。
  - 吊灯、吧台、甜点柜、咖啡机、黑板。
  - 店员会走动；有一位读报的常客，一只猫睡在椅子上。
  - 镜头从吧台后面看过去：前景是糖罐和插着勺子的玻璃杯。
- **洗衣房：**
  - 四台滚筒，只有一台跟着节奏转。
  - 洗衣液货架、挂钟、留言板、长椅上落下的一只袜子。
  - 折衣台、推车、洗衣液售货机，前景是洗衣篮和盆栽。
- **电车：**
  - 车厢里有长椅，坐垫边缘磨白了。
  - 吊环在摆，扶杆。
  - 窗外三层景物按远近不同速度后退，阳光斑在座椅上移动。
  - 前景是近侧座椅的椅背。
- **街道（一条连续的街）：**
  - 依次是他的楼、洗衣房、转角咖啡、电车站（报刊亭、两侧站台）、小广场（梧桐、长椅、花摊）、面包房、唱片行。
  - 楼上窗户各不相同：窗台花箱、晾衣绳、亮灯的窗帘。
  - 屋顶有水箱和天线，梧桐的树影会动。
  - 电车线、路灯和光锥，前景是暗一些的矮墙和绿篱，让字幕清楚。
