# 故事《LOVE SONG：一座城市的秘密排练》

**一句话：** 一个不太会表达的人写下一段旋律，旋律却先于他走出房间，穿过整座城市，去寻找那个他想唱给她听的人。

**情绪：** 有人花了很久练习如何表达喜欢，最后发现，对方早就记得他的节奏。

以下情节是原创改编，不是对歌词逐句内容的解释。

| 段落 | 发生了什么 |
| --- | --- |
| 前奏 | 他对着空椅子排练，说不出口。窗外骑车的人让他坐直，结果认错了人。纸上的墨迹聚成一颗琥珀色音符，它跳下纸，踩过杯沿，从窗口跑出去；他伸手，慢了一拍。 |
| 主歌 1 | 音符穿过一条小街：咖啡杯起涟漪，洗衣房的滚筒跟着转，电车里的吊环摆。她在咖啡馆窗边画小鸟，把杯柄转到左边，杯里出现熟悉的四下；同一时刻，他在房间里也敲着这四下。 |
| 副歌 1 | 她看见窗玻璃反光里的音符，先听了一会儿，再收好本子出门。整条街开始伴奏。他终于出门，追着音符走，差点撞上洗衣房突然推开的门。两人走在同一条街的两侧，谁也没看见谁。 |
| 主歌 2 | 他来到咖啡馆，她刚走。杯柄朝左，餐巾纸上是她画的小鸟。回忆：她曾一边画画一边敲这个节奏，他什么也没说，只是记了下来。他把自己的杯柄也转到左边。另一处，她把小鸟画在电线上，排起来正像那几个音符。 |
| 副歌 2 | 这次他自己选方向，音符跟在后面，路灯随他亮起。车站：他看见一个相似的背影，电车驶过挡住视线；车开走，她其实在对面站台。她回头时，他正低头去捡被风吹落的纸。她一路认出那些节奏的联系，在路灯杆上敲出后半句，整条街的灯一盏盏亮向远处。 |
| 桥段 | 他坐在长椅上，展开改了又改的纸，密密麻麻的线条把最初的旋律挤到角落。他把纸翻过来，只留下最初的动机。音符回来了，落在他手边。他不再追它，带着它往前走。 |
| 最终副歌 | 咖啡馆门外，他整了整袖口，敲出前半句，停住；她补上后半句。两段节奏第一次接上。音符落回纸上，成为普通的墨点。城市恢复日常，镜头留给两个人。 |
| 尾奏 | 回到开头的构图：这一次，那把椅子上坐着她。她在纸的背面画下小鸟。两人同时抬头，又不好意思地移开。她轻敲一下，他接上一下。镜头退到窗外，城市照常运转。 |

## 两个人都主动

- **他：** 从“对着空椅子排练”到“自己选方向”，再到“先站定、先敲出前半句”。
- **她：** 听见、寻找、判断、回应。
  - 在咖啡馆没有立刻追，先听。
  - 在洗衣房橱窗前认出节奏。
  - 一路把那些节奏连起来。
  - 主动在路灯杆上敲出后半句。
  - 最后补上那半句的也是她。

## 与歌词的关系

- 歌词逐句原样出现，不改写，也不把剧情文案混进歌词。
- 画面不对歌词做字面图解，只在两处让关键词进入环境：
  - 咖啡馆黑板上的 Love Song（副歌 1）
  - 纸背面写下的 Melody（桥段）
- 桥段里关于画和夜空的句子，对应拥挤得像一幅画的纸面、很亮的星星和屋顶上的月亮。
